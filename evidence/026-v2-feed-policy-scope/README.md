# Synthetic v2 feed-scope run

This is a portable subset of run B on 2026-11-22. [The pre-execution oracle](ORACLE.md) defines the bytes, expectations, and limits. The [harness](run_feed_oracle_sandbox.py), [inputs](inputs/), [command receipts and streams](logs/), and [inventory](inventory.json) retain the consumer experiment. [Receipt index](receipt-index.json) records SHA-256 of original and normalized receipts and the nine original inventory snapshots. All nine snapshot hashes are identical. The inventory excludes `.git`; it covers 756 consumer entries and 52 input entries. Inputs are unchanged exact bytes. Receipts replace the run directory, source checkout and Python executable path with `<RUN>`, `<CONSUMER_SOURCE>`, and `<PYTHON>` respectively; their original hashes and normalized hashes are indexed. Digest fields inside receipts describe the original streams, so a stream changed by path normalization has a different portable hash. No raw private path is needed to interpret them.

The recorded launch was `python3 -B work/v2-feed-oracle/run_feed_oracle_sandbox.py --consumer-source work/pkg1-codeql-openwrt --run-dir work/v2-feed-run-20261122-b`, exit 0; the execution tool reported 0.8 seconds wall time, not an independently timed benchmark. Python 3.15.2 and Git 2.56.1 were used on macOS 15.8.2 arm64; both source and disposable consumer reported clean at `48c6a65b7578234644c6b06780fc82ccf6d61a8b`. The harness digest is recorded in preflight and matches the retained harness. Individual subprocess argv, exits, elapsed monotonic time, and stdout/stderr are in the receipts; peak memory was not measured. There was no extraction or query phase.

The adapter subprocesses used `sandbox-exec -p '(version 1) (allow default) (deny file-write*)'` with `-B`, pipe-captured streams, owned TMPDIR and XDG cache. HOME was inherited, not run-owned, and setup Git commands ran outside the sandbox. A separate `sandbox-exec` probe with this profile attempted `touch` on a new path under the oracle directory and exited 1, `Operation not permitted`, without creating it. A second Python probe received permission errors on attempted exclusive file creation in `/tmp` and inherited HOME. These probes do not prove every write is blocked or authenticate execution. The inventory covers only the specified paths. Earlier run A produced the same fixtures and outcomes without sandboxing; run B is the reported run.

API calls use a wrapper which catches `ResolutionError`, prints a JSON exception object on stdout, and exits 2; that is the wrapper's protocol. The CLI itself emits `inapplicable reference\n` on stderr and exits 2 for the asserted stale case. The adapter validates policy before calculating the gate, so that error is not an observed gate result; the identical stale-policy inputs with null assertion produce gate allow. Records and hashes document consistency, not authenticated execution, source provenance, or a fresh producer handoff.

# Claim 027: Bounded markup CFG for normal and trim-open expression tags

**Status:** Demonstrated for two exact source fixtures and the pinned bounded API.

**Scope:** At producer `6010ff2c0f101f7629c6fe117a421f671c311a2b`, does a clean ordinary markup root for `{{ x }}` expose its exact bounded CFG path, and what does the same API expose for valid trim-open syntax `{{- x }}`?

**Out of scope:** Intended support policy for trim-open syntax, whitespace trimming at runtime, rendering, output escaping, identifier resolution, reachability, data flow, security, general markup CFG completeness, consumer handoff, and real-source coverage.

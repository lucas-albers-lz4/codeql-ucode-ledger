## Bounded v0.5 selection proposal

Use a source-staged, package-conditional OpenWrt v0.5 manifest containing the 12 paths present at this pin whose package/target recipe visibly carries them into the package or target filesystem: `fw_loadenv`; the three present `netifd` files; both hostapd helper scripts; `mdns.uc`; `unet.uc`; both `provision` files; `pkgen`; and ipq806x `base64decode.uc`. Preserve package or target conditions above as selection metadata; do not claim all 12 coexist in one image. Keep the five absent candidate paths unresolved and fail closed until the candidate inventory is regenerated or reconciled against this exact source SHA. This is not a claim that a package/image was built or that installed bytes match Git. The first follow-up should freeze the relevant package config and compare selected source identities with prepared package staging bytes for one package; no CodeQL work is proposed by this mapping alone.
